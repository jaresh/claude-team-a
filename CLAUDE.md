# claude-team-a

A playable browser roguelike built by an agent team. The game is the test vehicle; the product is
the reusable team kit in `kit/` (rules, install script, cost tool, experiment protocol).

- Game contracts, layout and commands: `game/ARCHITECTURE.md`
- Experiment log: `results/experiments.md`; cost reports: `results/metrics/`
