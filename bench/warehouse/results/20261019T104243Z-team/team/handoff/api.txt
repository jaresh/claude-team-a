ASSUMPTIONS (for README)
- Unknown body fields -> 400. Quantities, amounts, costs are JSON strings; numbers -> 400.
- hold accepts an int or a digit string (hours). Booleans are rejected.
- Idempotency: the first request with a key keeps its status and body, including 400/401/403/404/command errors. A same key with another path or body -> 409, unstored.
- A replay is answered with the stored response whoever sends it. A replay that fails the user or role check (or hits an unknown path or bad body) is caught in _answer, and _keep returns the stored answer for that key. So a same-key replay by a user without the role gets the first answer (for example 201), not a new 403.
- 500 for unexpected exceptions; the transaction is rolled back.
