Assumptions (spec silent)
- account add returns the created leaf account dict; parents are created silently and not audited (only the named account is).
- fx add: FROM and TO must be 3 uppercase letters; FROM == TO is a user error; rate must be > 0; stored and printed in
  plain (non-exponent) decimal text.
- convert: --at is required (argparse). Currency codes are validated the same way as fx add.
- period close: audited on every successful call, even when it changes nothing (the contract says exactly once on success).
  Spec 11 can be read as "only data-changing commands"; flip by moving the audit call under the `if` in close_period.
- txn descriptions are not checked (empty allowed).
- txn list --account matches the exact account or a descendant ("Expenses:Rent" does not match "Expenses:RentX").
- audit list --by NAME for an unknown or silent user returns [] (not an error).
- user add --role uses argparse choices (admin/editor/viewer), so a bad role exits 2 from argparse; add_user also checks.
- balance lists accounts sorted by name, currencies sorted; zero sums print "0.00".
