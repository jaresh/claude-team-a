Public API (plain functions, values not argparse args; each returns JSON-ready data)
- income_report(book, frm, to, currency=None) -> {"income": {acct: amt}, "expenses": {acct: amt}, "total_income", "total_expenses", "net"}
- balance_sheet(book, at, currency=None) -> {"assets", "liabilities", "equity", "retained_earnings", "total_assets", "total_liabilities", "total_equity"}
- networth(book, frm, to) -> [{"month": "YYYY-MM", "assets", "liabilities", "networth"}, ...]   (frm/to are YYYY-MM)
- tax_report(book, frm, to) -> {"collected", "paid", "net", "by_code": {code: {"collected", "paid"}}}
- reconcile(book, account, date, balance, clear_ids=()) -> {"account", "statement_balance", "cleared_balance", "difference", "uncleared": [txn ids]}; writes cleared rows and audits.
- trial_balance(book, at) -> {"rows": [{"account", "debit", "credit"}], "total_debit", "total_credit"}
- ledger(book, account, frm, to) -> {"account", "opening", "rows": [{"date", "id", "description", "amount", "balance"}], "closing"}
- register(reg): commands "report income", "report balance-sheet", "report networth", "report tax", "report trial-balance", "report ledger" (write=False); "reconcile" (write=True; --date, --balance, --clear ID, repeatable or nargs).

Assumptions (spec silent)
- Income and balance-sheet convert each (account, currency) total at the period end date, then sum per account. Ledger converts each posting at its own txn date (opening too).
- Income and liability/equity values are shown negated (sign flipped from raw balances). Retained earnings = income minus expenses up to the date.
- networth uses the book currency (spec has no --currency for it). Trial balance uses the book currency.
- Tax: invoices count when status != 'draft' and date in range; bills count by bill date. invoice_lines and bill_lines tax amounts are assumed to be in the book currency (no currency column in those tables). NULL tax_code rows are skipped.
- reconcile: all clear ids are validated before any insert, so a bad id changes nothing. Clearing is idempotent (INSERT OR IGNORE). "uncleared" lists txn ids with a posting to the account on or before the date that are not cleared, ascending.
- Report commands need no --user (read-only). from > to, or a malformed date or month, raises UserError (exit 2).
