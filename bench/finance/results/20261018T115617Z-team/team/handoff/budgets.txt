## Assumptions
- `budget set` requires write access (viewer gets Forbidden, unknown or missing user gets Unauthorized). The account must exist and have type `expense`, else UserError. A replace is an INSERT OR REPLACE on (account, month).
- The amount goes through parse_money and is stored as fmt() text, so it has two decimals. Negative budgets are accepted; the spec does not forbid them.
- Closed periods (check_open) are not checked for budget set, because a budget is not a transaction.
- `actual` sums the raw signed posting amounts (debits positive, as expense postings are) for postings in the account and descendants (exact name or `name:` prefix), with the month taken from transactions.date. No currency conversion.
- `report budget` needs no user and lists only accounts with a budget row for that month, sorted by account. `remaining` = budget − actual, so it can be negative.
- The cli MODULES names are "fin.budgets" (not "budgets"). Use that in any test that calls cli.main(modules=...).
