- Assumptions made (list these in README.md):
  - `fx add` rejects FROM == TO (a user error); the rate must be a finite decimal > 0 and is stored as a plain (non-exponent) string.
  - `txn list --account P` matches P itself and descendants via prefix "P:" (so "Expenses:Rent" does not match "Expenses:Rentals").
  - `balance` lists each account/ancestor and each currency that has postings under it, including zero sums ("0.00"). Keys are sorted.
  - `txn add` description is not checked for emptiness; `--posting` is required to produce at least two postings (post_txn enforces this).
  - `convert` and `fx add` upper-case currency codes via currency_code; `convert` uses book.convert, so the same currency is 1:1 and a missing rate is a user error.
