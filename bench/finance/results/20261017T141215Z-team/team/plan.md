## Contract / Conventions (the lead already wrote `fin/core.py` and `tests/helpers.py` — READ THEM FIRST, they are short)
- Never re-implement what core has: `UserError` (raise for every user error), `D/q2/fmt/parse_amount/parse_date/parse_month/parse_currency`, `add_months/add_days/days_between/month_end/months_range`, `ensure_account/get_account/post_txn/txn_dict/account_sums/rollup/convert/convert_sums/get_rate`, `check_open` (post_txn already calls it), `Context` (`ctx.conn`, `ctx.user`, `ctx.currency`, `ctx.audit(action, target)`), `group/add_cmd`, `list_audit`.
- Money is Decimal; JSON amounts always via `fmt()`. Never float.
- Each module `fin/<mod>.py` has `setup(sub)` registering its commands with `group(sub,"name")` / `add_cmd(sub_or_group, "cmd", handler, perm)` (perm `read`/`write`/`admin`), optional `SCHEMA` (SQL, `CREATE TABLE IF NOT EXISTS`, run on every connect), and handler `h(ctx, args)` returning the JSON-able result. Handlers are thin wrappers over plain functions `fn(ctx, **kwargs)` (listed below) which hold the logic and which the HTTP layer calls; plain functions take already-parsed strings (dates as str) and validate through core. Handlers/functions never commit or catch UserError: main wraps write commands in a transaction (rollback on error, so partial work is undone). Every write command calls `ctx.audit(action, target)` exactly once on success (inside the plain function). The `report` group is shared: `group(sub,"report")` from any module.
- Errors: raise `UserError("message")`. Never print, never `sys.exit`.
- Tests: `tests/test_<task>.py`, `unittest`, subclass `tests.helpers.BookTestCase` (`self.ok(...)` parses JSON of a successful command, `self.err(...)` asserts exit 2/empty stdout, `self.txn(...)`). Cover every command of your task, errors, audit entries, roles (viewer denied, editor ok) where relevant. Do not edit `fin/core.py`, `tests/helpers.py`, `tests/test_core.py` or other tasks' files; if core needs a change, write it to your handoff and work around it.
- Keep code simple, no dead code, comments only where non-obvious.
