Assumptions for README
- POST with an empty body is treated as {} (so /invoices/ID/issue needs no body). A missing required field is 400.
- Invoice line descriptions cannot contain ";" (the CLI line format splits on ";"), so such a line gets 400.
- Payment amount is passed after "--", so a value like "-5" or "--help" is the positional amount, not an option.
- Bad JSON, a non-object body, or an invalid Content-Length -> 400. Non-ASCII JSON is returned as UTF-8 (ensure_ascii=False).
- Access is per command: viewer gets 403 on writes; editor/admin follow the CLI roles.
