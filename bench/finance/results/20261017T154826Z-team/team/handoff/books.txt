**Decisions and assumptions (for README)**
- period close audits inside the function via cli.audit, not via set_defaults(audit=...): a no-op close (month not later than closed_through) changes nothing and writes no audit entry. The contract's audit lambda cannot skip an entry, so this is the only way. The lambda is not set for this command.
- init on an existing book (meta currency present) is a user error. If validation fails, the db file may still be created by open_db with an empty schema (cli creates it before the command runs); no rows are written.
- txn add: description must be non-empty; amounts with more than two decimals are rejected; at least two postings (core).
- fx add: rate must be > 0; FROM must differ from TO; rate stored as a plain decimal string (format 'f'), so 1E+1 is stored as 10.
- convert: --at is required (no default date).
- balance: includes every account on or below a posted account (zero balances included when they have postings); keys sorted; currencies sorted.
- txn list --account matches by segment (Assets matches Assets:Bank, not Assets:Ban).
- user add --role uses argparse choices (admin, editor, viewer); invalid role is exit 2.
- audit list --by filters on user name; no --by lists all.
- Empty names (user, admin, description) are user errors.
