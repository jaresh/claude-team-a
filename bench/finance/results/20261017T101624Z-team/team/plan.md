# Plan
**Goal**: small-business finance system, stdlib Python, per .claude/team/spec.md (read your sections there).

## Contract (already built by lead; READ fin/core.py, fin/cli.py, fin/admin.py, tests/helpers.py, tests/test_admin.py first)
- Each command module is `fin/<module>.py` with `register(sub)`; it adds parsers like admin.py does (nested `sub.add_parser("txn").add_subparsers(dest="sub", required=True)`), each leaf `set_defaults(func=handler, perm=...)`. perm: "read" (no user needed), "write" (admin/editor), "admin", "none" (needs no db, ctx.conn is None, e.g. loan schedule). Handler: `def handler(ctx, args)` returns a JSON-able object (strings for money, via core.fmt); cli prints it. Raise `core.UserError` for user errors; the CLI rolls back everything. Never print. Do NOT call commit.
- Data-changing handlers call `core.audit(ctx, action, target)` once (spec section 11 for names).
- Split each command into a plain function usable by the HTTP API too: `def do_xxx(ctx, ...) -> result` with the handler a thin wrapper from args. Names listed per task below.
- Use ONLY core helpers: core.UserError, q/fmt/dec/amount, parse_date/parse_month/currency_code, add_months/add_years/month_end/next_month, post_transaction (all postings of every txn go through it; it enforces balance, unknown accounts, closed periods), parse_posting, txn_json, ensure_account/require_account/get_account/account_type, convert, book_currency. Tables already exist in core.SCHEMA (do not change core.py; if you truly need a change, add a line to .claude/team/changes.md and make it tiny and additive).
- Money in SQL is stored as TEXT decimal; sum with Decimal in Python, never float.
- Tests: `tests/test_<module>.py` using tests.helpers.BookTest (self.ok/self.fail/self.txn/self.accounts). Cover every command & error case in your spec sections. Don't edit other tests.
- Missing --user for write commands, role checks and audit are handled by the framework except the audit call.
- Style: concise, no comments beyond docstrings, argparse as in admin.py.
