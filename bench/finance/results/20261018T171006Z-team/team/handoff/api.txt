**Decisions made (lead may want to confirm)**
- `serve --port` defaults to 8000 (spec says `--port N`, plan lists it without a default).
- Unknown methods other than GET/POST/PUT/PATCH/DELETE get the stdlib's 501 (no do_OPTIONS/do_HEAD).
- Any unexpected exception in a handler -> 500 `{"error": "internal error"}` with a traceback on stderr.
- POST body scalars are converted with str() (so JSON numbers like 145 work for amounts); a missing
  or null required field -> 400 `{"error": "missing NAME"}`.
- Invoice line description with ";" is passed through, so invoicing's own 4-field check reports it as a 400.
