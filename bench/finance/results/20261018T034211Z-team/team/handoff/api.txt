Assumptions (for the README)
- Server binds 127.0.0.1 only.
- Invoice line fields (description, quantity, price, tax_code) containing ';' are rejected with 400, because the command line format uses ';' as separator.
- GET /audit and GET /transactions take no filters.
- Unknown paths give 404; HTTP methods other than GET and POST (e.g. DELETE) get the http.server default 501.
- Internal errors give 500 with a generic body; details only go to stderr.
- serve returns {"stopped": port} when interrupted with Ctrl-C.
- Request bodies may hold numbers as well as strings (kept as written, then passed to the command).
