Assumptions (unspecified details decided here)
- txn add: a blank or whitespace-only --desc is a user error.
- txn list: --from later than --to is not an error; it returns an empty list. --account matches the account and its descendants only ("Expenses:Food" does not match "Expenses:Foodstuff"). No check that the --account name exists.
- balance: a currency that has postings and sums to zero shows "0.00"; keys sorted; accounts with no postings on or before --at are omitted.
- account add: returns {name, type, currency} of the account named (not of the created parents). An empty --currency is treated as not given (book currency).
- fx add: rejects non-positive rates and a pair with the same currency on both sides; stores the rate as a plain decimal string; returns {date, from, to, rate}.
- convert: --at is required (argparse). Returns {amount, currency}; same currency returns the amount rounded to cents.
